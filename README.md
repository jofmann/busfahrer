# 🍻 Busfahrer

**Busfahrer** is a classic **drinking game** turned into a modern web app.  
Built with **React** and **Tailwind CSS**, the app provides a clean and responsive UI for playing the game directly in the browser.

👉 **Live Demo:**  
https://busfahrer.vercel.app

---

## 🎮 About the Game

Busfahrer is a popular card-based drinking game.  
Players go through different rounds, make guesses, and drink when they lose — simple rules, lots of fun 🍺

---

## 🚀 Features

- 🍻 Digital version of the Busfahrer drinking game
- 🃏 Interactive game flow
- ⚡ Fast and lightweight React app
- 🎨 Modern UI styled with Tailwind CSS
- 📱 Fully responsive (mobile & desktop)

---

## 🛠️ Tech Stack

- **Framework:** React  
- **Styling:** Tailwind CSS  
- **Language:** JavaScript  
- **Deployment:** Vercel
